## Overview

A tree-structured (outline-style) cloud memo app.

Due to server capacity limitations, it's currently limited to 50 accounts and is only available to acquaintances (the launch button on this page is disabled).

It uses Google account login, and user identification is also based on the Google account.

(Because it's not registered in the app store, the initial login warning is quite strong and requires multiple taps.)

### How it works
Notes are organized in a tree structure and saved to the cloud.
The same data can be accessed from multiple devices.
Attachments are saved to the Google Drive of the logged-in Google account to save server space.

### Features
I added features as I thought of them, and it ended up being unusually feature-rich.
Explaining everything would be too long, so I'll give a brief overview...

### Basic...or maybe not so basic... text editing functions
"Undo/Redo," font size, 11 font types, headings, bold/italic/underline/strikethrough, text color/highlighter, left/center/right alignment, bullet points/numbered lists/checkboxes, quotes, code blocks/URL links/table insertion/YouTube embedding/search

### Advanced editing functions
- "Category" function to completely replace the node tree
- Table of contents
- Collapse
- Attachments (text/images/audio/video)
- Web publishing (with comment function)
- Display descendant nodes together

...and several other functions that I don't remember if I properly implemented.

### Functions other than settings and editing
- Adjust the display direction and width of the node list
- Import/export
- Adjust line spacing
- Automatic backup

I still think it's overkill!

Since I'm the only one using it at this point (about six months after creation), there are various rough edges in the details.

For example, there's a system that warns you if editing conflicts occur when opening a file on multiple devices, but for some reason, warnings pop up frequently even when I'm only using it on one device.
